# Elegant Women's Fashion - Shopify Theme

A modern, elegant Shopify theme designed specifically for women's clothing stores. Features a clean design with smooth animations and mobile-responsive layout.

## Features

- ✨ Modern, elegant design
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎨 Customizable color scheme
- 🛍️ Product quick view hover effects
- 🎯 Featured collections
- 📰 Newsletter signup
- 🔍 Search functionality
- 🛒 Cart page with quantity updates
- 👤 Customer account pages
- 🎭 Multiple sections (Hero, Collections, Image with Text)
- ⚡ Fast loading with optimized CSS
- ♿ Accessibility features

## Installation

1. **Download the theme files**
   - The theme is in the `shopify-womens-theme` folder

2. **Compress as ZIP**
   - Select all files in the folder
   - Right-click and choose "Compress to ZIP"
   - Name it `elegant-womens-fashion.zip`

3. **Upload to Shopify**
   - Go to your Shopify Admin
   - Navigate to **Online Store → Themes**
   - Click **Add theme**
   - Select **Upload ZIP file**
   - Choose your `elegant-womens-fashion.zip`
   - Click **Upload**

4. **Activate Theme**
   - Once uploaded, click **Publish** to make it live

## Customization

### Colors
Go to **Theme Settings → Colors** to customize:
- Primary Color (default: #d4a373)
- Secondary Color (default: #f5e6d3)
- Text Color (default: #2c2c2c)

### Logo
Upload your logo in **Theme Settings → Header**

### Navigation Menu
Create your menu at **Navigation → Menus**

### Social Media
Add social links in **Theme Settings → Social Media**

### Home Page Sections
The home page includes:
- Hero Banner (full-width image with heading)
- Featured Collection (showcase products)
- Image with Text (brand story)
- Collection List (category grid)
